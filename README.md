# Fintech-loan-app-UI-Design-FigmaMcp

金融借款类 App UI 全套设计技能（Figma MCP）。

三个出发点：遵循交互原型 · 符合当地用户审美 · 给前端清晰明确的交付规范。

覆盖：新需求先原型后视觉、页面换肤（交互与内容不变）、插画生成与贴屏、Logo（切图法 / 升级精修 / 唯一最终版）、商店图（1080×1920）、组件库与状态变体、设计变量（颜色 / 间距 / 圆角，含代码名）与样式、全页面 QA、切图导出、按类别分区的前端交付规范，以及 Figma Plugin API 踩坑清单。

适用市场示例：印尼（OJK / AFPI 合规），其他市场按当地语言与合规调整。

## 安装

把 `SKILL.md` 放到 Claude 技能目录下的 `fintech-loan-app-ui-design-figmamcp/` 文件夹，例如：

```
~/.claude/skills/fintech-loan-app-ui-design-figmamcp/SKILL.md
```
