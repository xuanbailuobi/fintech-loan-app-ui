# fintech-loan-app-ui

金融借款类 App UI 全套设计技能（Figma MCP）。

覆盖：页面换肤（交互与内容不变）、插画生成与贴屏、Logo（切图法 / 升级精修 / 唯一最终版）、商店图（1080×1920）、原子设计组件库、色板与变量、文字样式、插图/物料/Icon 库，以及 Figma Plugin API 踩坑清单。

首个验证项目：Gradana（印尼，OJK / AFPI 合规）。

## 安装

把 `SKILL.md` 放到 Claude 技能目录下的 `fintech-loan-app-ui/` 文件夹，例如：

```
~/.claude/skills/fintech-loan-app-ui/SKILL.md
```
